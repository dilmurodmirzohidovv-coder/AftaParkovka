# ParkTop

Parkovka qidirish loyihasi: React + Vite frontend va Node.js + Express backend.

## 1. O'rnatish

Loyiha ildizida:

```bash
npm install
npm --prefix backend install
npm --prefix frontend install
```

## 2. Backend

```bash
npm run dev
```

Backend:
http://localhost:5000

Tekshirish:
http://localhost:5000/api/health

## 3. Frontend

Ikkinchi terminal:

```bash
npm run frontend
```

Frontend odatda:
http://localhost:5173

## 4. Agar `Missing script: dev` chiqsa

Siz loyiha ildizida turishingiz kerak. Endi ildiz `package.json` ham mavjud, shuning uchun:

```bash
npm run dev
```

to'g'ridan-to'g'ri backendni ishga tushiradi.

Node.js 18 yoki undan yuqori bo'lsin.
